## 故障演练矩阵(部署后逐项演练)

| 演练 | 操作 | 预期 |
|------|------|------|
| 断网 | 互动中拔后端网络 | 前端错误提示,不白屏;恢复后可重新开始 |
| 麦克风拒绝 | 浏览器拒权限 | 明确提示,文字输入兜底可用 |
| 静音上传 | 对麦克风不出声 | "没听清"提示,可重新录新音频 |
| 连点麦克风 | 快速多次点击 | 说话/处理期间按钮禁用,无重复提交 |
| 退出时正在播放 | 播报中点 ✕ | 语音立即停止,录音轨关闭,服务端会话删除 |
| 180s 到时 | 挂在互动页不动 | 温和收尾回到结束页,服务端会话删除 |
| 闲置 60s | 选完主题不操作 | 温和收尾回到结束页 |
| 404 会话 | 会话被服务端清理后继续说话 | 回到首页,提示重新开始 |
| 限流 | >12 轮/分钟(脚本) | 429,前端温和提示 |
| 服务重启 | 互动中重启后端 | 旧会话 404,前端回首页重新开始 |
