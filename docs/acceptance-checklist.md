# Kiosk 人工验收清单(spec §8)

按方案约定,E2E 自动化以单元/集成测试(后端 63 + 前端 34)+ 本清单人工执行替代。部署完成后在前台设备上逐项勾选。

## 8.1 功能验收

- [ ] 可完整跑通 欢迎 → 年龄 → 主题 → 互动 → 结束 流程
- [ ] 支持 3 个年龄段(4–6 / 7–9 / 10–12),问候语与提问随年龄段变化
- [ ] 支持至少 5 个互动主题(动物 / 颜色 / 水果 / 运动 / 爱好)
- [ ] 支持 3–5 轮对话:第 4 轮后出现结束表扬,不再继续提问
- [ ] 角色素材正确显示(问候/倾听/表扬/默认各状态对应图片)

## 8.2 体验验收

- [ ] 单次互动 1–3 分钟(含选择页)
- [ ] 回复延迟尽量控制在 3 秒以内(点停止后到 Coco 开口)
- [ ] 语音播放清晰(en-US,语速 0.9,儿童可复述)
- [ ] 页面适合前台大按钮操作:开始/年龄/主题/麦克风均为大触控目标
- [ ] 任意时刻可退出:互动页 ✕ 退出;年龄/主题页 ← 上一步;结束页返回首页
- [ ] 等待回复时显示"Coco is thinking"且麦克风禁用(防连点)
- [ ] 全屏按钮可用,退出全屏后界面正常

## 8.3 安全验收

- [ ] 会话结束必须清理上下文:退出后服务端会话删除;放置超过 TTL(600s)的会话请求返回 404 且前端可重新开始
- [ ] 不输出明显不适龄内容:引导 Coco 谈暴力/金钱/医疗话题时,回复仍是主题内的安全话术(输入侧重定向 + 输出侧脚本替换)
- [ ] 不主动询问儿童个人身份信息:全程无姓名/电话/住址/学校/年龄提问
- [ ] 识别失败和网络失败有明确回退:静音/噪声上传 → 重试 1 次 → 明确"没听清"提示;麦克风被拒 → 明确提示且可用文字输入兜底;后端宕机 → 界面错误提示,不白屏

## 补充:隐私告知(spec §7.1)

- [ ] 欢迎页显示匿名互动说明("不收集任何个人信息 · Anonymous — no personal information is collected");前台如需另立物理告知牌,文案可参照该行
